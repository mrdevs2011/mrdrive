Bu havola faqat sizniki. Name + token birga Claude da hisobingizni aniqlaydi.

Claude da qayerga qo‘yiladi?

  1. Brauzerda oching: claude.ai
  2. Chap pastki burchakdagi profilingiz → Settings
  3. Chap menyudan Connectors ni tanlang
  4. Add custom connector (yoki “Add connector”) tugmasini bosing
  5. Remote MCP server URL maydoniga yuqoridagi havolani joylashtiring (ko‘z belgisi bilan ochib, nusxalang)
  6. Nom bering (masalan: MRdrive — Muhammadrasul) va saqlang
  7. Chatda sinab ko‘ring: «MRdrive da nima bor?»

Bir nechta MRdrive hisobi bo‘lsa — har biri uchun alohida connector qo‘shing. Claude da ular name orqali farqlanadi.
