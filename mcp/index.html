Agent ulanish

MCP havolasini agent sozlamalariga qo‘ying.

Faqat sizniki. Boshqaga bermang.

Qanday ulash

  1. claude.ai → Sozlamalar → Ulashlar
  2. «Maxsus ulanish» → MCP URL maydoniga havolani qo‘ying
  3. Saqlang va chatda sinab ko‘ring

Claude Desktop yoki claude.ai web — ikkalasida ham ishlaydi.

  1. Grok (x.com) yoki Grok ilovasida sozlamalarni oching
  2. Connectors / MCP bo‘limiga o‘ting
  3. MCP URL ni qo‘ying va ulanishni tasdiqlang

Grok MCP qo‘llab-quvvatlashi muhitga bog‘liq — URL ni nusxalab qo‘ying.

  1. Cursor → Settings → MCP (yoki Features → MCP)
  2. «Add new MCP server» → URL ni joylashtiring
  3. Saqlang, agentni qayta ishga tushiring

Cursor IDE da MCP server sifatida qo‘shiladi.

  1. VS Code da MCP qo‘llab-quvvatlovchi extension o‘rnating (masalan Continue, Cline yoki Copilot agent)
  2. Extension sozlamalarida MCP servers → Add server
  3. Type: URL, value: yuqoridagi MCP havola
  4. Saqlang va chat/agent paneldan foydalaning

Oddiy VS Code o‘zi MCP bilmaydi — extension kerak.

  1. Windsurf → Settings → Cascade / MCP
  2. «Add MCP server» → URL ni qo‘ying
  3. Saqlang va Cascade agent bilan sinab ko‘ring

Windsurf (Codeium) Cascade MCP ulanishini qo‘llab-quvvatlaydi.

  1. Zed → Settings (settings.json)
  2. context_servers yoki MCP bo‘limiga server qo‘shing
  3. URL sifatida yuqoridagi MCP havolani yozing
  4. Zed ni qayta oching

Zed agent / context server orqali MCP ulanadi.

  1. Goose ni o‘rnating (Block)
  2. goose configure yoki config faylida MCP server qo‘shing
  3. Type: sse/http, URL: yuqoridagi MCP havola
  4. goose ni ishga tushirib sinab ko‘ring

Goose CLI agent — MCP orqali tool chaqiradi.

  1. LibreChat librechat.yaml (yoki Admin → MCP) ni oching
  2. mcpServers bo‘limiga yangi server qo‘shing
  3. type: sse yoki streamable-http, url: MCP havola
  4. LibreChat ni qayta ishga tushiring

Self-hosted LibreChat MCP serverlarni config orqali ulaydi.
